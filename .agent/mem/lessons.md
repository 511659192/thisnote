# Lessons

> 2026-10-12 起的用户纠正按主题提炼，2026-10-17 压缩：移除一次性事件记录与已升级进 `AGENTS.md` 的条目；每条 = 执行规则（+依据）；同类错误 ≥2 次标记【硬规则】。

## 百度网盘同步
- 【硬规则】云 API 语义以官方文档为准，不套用其他 SDK 的枚举含义：上传冲突覆盖用 `rtype=3`，precreate 与 create 都要传；create 响应的实际路径须与请求目标核对；不擅自清理用户云端已有副本。
- 云端列表 MD5 不是内容 MD5：双端比较与持久化基线用 `size:mtimeSeconds`，旧 MD5 基线视为缺失；下载仅在有效 `Content-MD5` 时校验摘要，否则校验服务端报告大小。
- "批量"仅指文件管理 API（移动/删除 ≤50 项/次）；上传无远端批量 API（单文件 precreate+分片+create），不按 50 项切组，本地并发按授权规格（8 线程 + 256 有界队列），不得称为批量上传。
- 文件同步在调用线程内逐个上传，全量与事件同步可并发（无执行器、无 running 短路，`status` 仅展示）；文件变更事件只记录载荷留 TODO，不以全量扫描代替。
- 下载为流式原地覆盖、无临时文件，发布事件前校验字节数与可用真实 MD5；中断时目标文件可能不完整（用户已知悉）。

## 前后端接口契约
- 【硬规则】契约沿数据流核对：请求体字段须与后端 DTO 一致（曾前端发 `contentMd`、后端读 `content`，只建成空白卡片）；UI 命名与 HTTP 字段不同时在调用处显式映射。
- 单值响应直接返回字符串，不包 DTO；改动后检查控制器、服务、前端解析与 DTO 无残余引用。
- 纯查询用 GET 且路径保留动作名；创建/修改/删除等有副作用的操作用 POST 并在路径标明动作。

## 需求范围与实现路径
- 【硬规则】只做用户明确提出的功能点：不自行增加存量 ID 改写、数据/状态迁移、别名、兼容层，不新增协调服务/事件；先追踪现有调用链，优先复用已有方法。
- 改完检查新增的孤立代码；删除文件前说明影响并取得确认。
- 精简防御分支以可读性为目标：先核对业务约束与全部调用点，只删证实不可能的分支，保留保护真实数据风险的逻辑。
- 纯重启只停启服务，不默认构建；仅在用户要求或源码/产物变更时构建（实测 clean 0.5s / package 11s / 前端 5s）。

## 前端 UI
- 【硬规则】「Enter 与 blur 共用提交函数且提交会关闭编辑态」的实现，入口必须可重入防护（如 `if (!renaming) return` 或在途标记）：卸载引发的 blur 会带同一草稿重入（曾致改标题双发 /api/notes/update）；NoteList 的 `savingNoteId` 是已验证的同类守卫。
- 【硬规则】UI 指代先定位具体组件层（页眉、页签导航、卡片元数据是不同目标），不从截图或旧界面推断，指代不清先确认。

## 插件与文件持久化
- 数据根目录统一由 Spring `thisnode.data-root`（默认 `${user.home}/.thisnode`）派生：笔记根 = `data-root/notes`，插件数据 = `data-root/notes/plugins/<pluginId>`；不做旧路径迁移兼容，少调用点的路径拼接直接内联、不留纯封装工具类。
- 领域模型留在插件内部（Notes 用 `CardPO`），跨插件走 plugin-api 的 `CardDTO`/`CardMetaDTO`；导入插件经 Notes API 使用，不直接扫描 Notes 目录或解析磁盘格式。
- 不保留多余监听器、不发布无人处理的事件：卡片创建申请监听器已兼管笔记创建，导入侧对缺 `CardMeta` 的文件发卡片创建申请即可。
- FileHelper 是插件文件操作与变更事件的统一入口，调用方不传发布器；持久写/删/移成功后发布带绝对路径的事件（重命名另带旧 URI），临时文件清理不发布；跨插件事件须经主容器发布，FileHelper 单例在插件上下文 refresh 前注册。
- 【硬规则】插件全量改名须同步：插件 ID、plugin-api 公共事件类型及消费者、Maven/PNPM 模块名、资源与数据路径、物理目录、workspace 与 lockfile；交付前全局搜索旧命名。

## 其他
- 表达业务约束不用布尔 `!=`/`==` 压成异或式校验，拆成直观的独立 `if`，让每种非法组合及其错误信息一眼可读。
- 交付表述区分「源码已实现」与「运行中已生效」：新响应字段未构建/重载前不声称界面已呈现；前端对旧响应缺字段显示明确「不可用」提示，不留空或伪报 0。
